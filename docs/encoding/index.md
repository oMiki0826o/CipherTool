# 編碼工具

CipherTool 的 Base16、Base32、Base64、摩斯電碼與 URL Encoding 都是表示法或傳輸格式，不是保密加密。任何人只要知道格式都能還原原始資料。

- Base16／Hex：每個位元組以兩個十六進位字元表示。
- Base32：以 32 個字元表達二進位資料，常見於較不易誤讀的文字環境。
- Base64：把二進位資料轉成可傳輸的 ASCII 字元；它不是「加密過的文字」。
- 摩斯電碼：用點、劃與間隔表示字元。
- URL Encoding：把 URL 中不安全的字元轉成 `%HH` 形式。

舊版的 [編碼與文字轉換說明](../encoding.md) 與 [摩斯電碼說明](../morse-code.md) 仍可作為快速查詢；這個入口用於把工具與古典密碼教材清楚分開。
