# 古典密碼百科

CipherTool 目前收錄二十種適合學習與解題的古典密碼。它們大多可用紙筆重現，因此也大多能被頻率分析、已知明文或暴力枚舉破解；請不要把它們當成現代保密技術。

## 共通提醒

「可解密」不等於「安全」。許多頁面的關鍵字、位移、矩陣或輪盤位置只是在重現歷史規則。現代系統應使用經過審查的加密協定與函式庫，而不是自行把多種古典方法疊加。
