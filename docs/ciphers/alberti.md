# 阿爾伯蒂密碼盤（Alberti Cipher Disk）

> 分類：密碼盤概念的簡化模擬。CipherTool 參數：`position`，0 到 25；目前實作等價於固定位置的凱薩位移。

## 歷史與本工具的範圍

Leon Battista Alberti 在文藝復興時期提出可旋轉的同心字母盤，常被視為多表替換概念的重要先驅。外圈與內圈各有字母，旋轉內圈即可改變對應表；歷史上的使用者可在訊息途中依約定換盤位，因此同一明文字母不一定始終對到同一密文。這個「可切換字母表」是它在密碼史上的價值。

CipherTool 提供的是教育用基本模擬，不會在訊息途中自動旋轉，也不包含歷史盤面的混合字母、數字或控制符號。`position` 只設定一個固定內圈偏移，因此目前行為等價於凱薩密碼的固定 shift：加密為 `C=(P+position) mod 26`，解密為 `P=(C-position) mod 26`。文件必須誠實區分「歷史密碼盤」與「本工具的固定盤位版本」，不可把本工具宣稱成完整 Alberti 機制。

## 操作、例子與限制

以 position 3 處理 `ABC`，輸出 `DEF`；再用 position 3 解密便回到 `ABC`。工具保留大小寫與非英文字元，僅替換 ASCII A–Z、a–z。position 必須是 0 到 25，0 表示內外圈未相對旋轉，輸出不變。手算時可畫兩個同心圓，將內圈向右轉 position 格，再查對應；程式則以模運算完成同一件事。

真正的阿爾伯蒂盤若在傳遞中切換位置，需要收發雙方以指示字元、約定時間或共同規則同步。固定 position 不具這種多表特性，頻率分析與二十六種位移枚舉即可破解。即使完整歷史版本也不適合現代安全需求；本工具更只適合理解密碼盤、位移與狀態同步。它不提供完整性、認證或安全 key 管理，不能用於敏感資料。

## 自我檢查

以 position 3 加密 `XYZ xyz`，應得 `ABC abc`；再解密應完全還原。輸入 26 或 -1 應被拒絕。這驗證了繞回、大小寫與參數範圍。

## 密碼盤和位移表的關係

把外圈固定為 ABC…Z、內圈轉動 position 格後，從外圈讀一個字母、在內圈找同位置字母，正是凱薩位移的實體化表示。position 0 時兩圈對齊，A 對 A；position 1 時 A 對 B；position 25 時 A 對 Z。用圓盤而非直線字母表的好處是繞回自然可見：內圈轉過最後一格會回到第一格。程式以模二十六達到同樣效果，沒有實際繪製圖形也不需要桌面圖形環境。

歷史上真正有趣的部分是盤位可改變。若每十個字母轉一次、或以特定指示字元切換，整份訊息會使用多張替換表，這就開始接近多表替換；但收件者必須知道何時轉動、轉多少及如何辨識指示。CipherTool 沒有實作這些狀態規則，因為若沒有把協定完整定義，任意「自動旋轉」反而難以重現。本工具的 position 是一個明確、靜態的參數，適合比較密碼盤概念與凱薩公式。

## 使用情境與常見誤解

常見誤解是以為盤狀外觀本身使密碼安全。實際上，若 position 固定，攻擊者只需嘗試二十六種結果；就算盤位會變，若切換規律公開或可從密文推測，仍能分析。器具能讓人方便地執行規則，但不會自動創造難以猜測的秘密。現代密碼學同樣可用硬體實作，但安全取決於演算法、金鑰、隨機性與協定，而非裝置看起來是否複雜。

另一個誤解是把 `position` 當成可以隨意輸入的大數。數學上 29 和 3 等價，但 GUI 的公開規則要求 0 至 25，讓使用者不必猜測是否自動化簡。若題目寫「內圈向左轉三格」，需先把方向換成本工具的正向位移約定；方向相反時應填 23，而不是 3。先用 A 的結果校驗方向最可靠。

## 手算練習與安全邊界

畫兩列字母，將下列向右移 position 格，即可代替畫圓盤。以 position 7 轉換 `MIXED Case!`，只處理 M、I、X、E、D 與英文字母部分，空白和驚嘆號保留。再用同一 position 反向轉換，輸出應逐字相同。這個練習可驗證大小寫和非字元規則，也能看見固定替換保留重複模式。

本工具不適合保護任何敏感資訊；它不產生隨機 key、不驗證來源，也不防止竄改。若需求是展示文藝復興時期的可旋轉字母盤，本頁的限制正是重要教材，而不是需要掩蓋的功能不足。

盤面變換也帶出一個重要歷史問題：訊息中用來告知「現在換盤」的符號本身若過於規律，會給分析者提示；若沒有指示，收件者又無法同步。這是從手工密碼走向協定設計時必須面對的取捨。Alberti 的創意在於提出切換表的可能，不在於已解決所有同步與安全問題。理解此點，才能正確評價它在密碼史上的進步與限制。

若讀者想把本工具作為繪製密碼盤的輔助，應把 position 視為內圈相對外圈的固定位移，而不是「第幾個字母」。例如 position 1 的內圈 A 位於外圈 Z 的對應位置或反向描述，取決於畫圖時選的方向；最可靠的校正仍是以工具的 `A→B`（position 1）實測後標註圖盤方向。這樣能避免紙上旋轉方向和程式公式相反。

進一步比較時，可將同一明文分別以 position 0、1、13、25 處理。0 是恆等映射，13 剛好是 ROT13，25 等價於向後一格。這四組能直觀展示密碼盤位置如何改變替換表，也能驗證程式的模二十六繞回。它們不是四把安全 key，而是四個方便檢查的教材基準。

歷史盤常含有非字母或混合字母表，這會影響表大小與公式的模數；本工具固定二十六字母，故所有數學都以 mod 26 進行。若看到不同盤面，不能只複用 position 數字，必須先確認其字母順序和符號集合。

在操作紀錄中，寫下「Alberti position 7」比只寫「轉盤加密」更可重現；前者同時交代了本工具的唯一可變設定與版本限制。這種把參數明文化的習慣，也能避免古典密碼題因方向或表格不同而產生看似矛盾的答案。

使用此頁做歷史比較時，請將「固定盤位模擬」與「歷史上可能多次換盤」分開記錄。前者可用單一 position 完整重現，後者還需要一份變換時序表；缺少時序表的描述並不是完整密碼規格。

因此本工具最適合回答「固定內圈位置如何改變字母對應」這個問題；若問題涉及傳訊途中轉盤，必須另外定義狀態表與切換指令，不能從目前輸出推論出未實作的行為。

阿爾伯蒂的歷史意義還在於把「密鑰可以隨時間改變」變成實體可操作的概念。這一點影響後來的多表替換設計；但要把概念變成可靠協定，仍需定義變更時機、同步失敗後如何恢復、以及指示字元是否會洩露規律。這些在本簡化固定盤位版本都刻意不實作，讀者不應自行腦補成已存在功能。

從使用者介面觀點，position 是可見參數，並非安全儲存的金鑰。若他人能看到輸入欄、設定檔或螢幕截圖，就能立即重現結果。即使 position 沒外洩，二十六種嘗試也沒有實際攻擊成本。用這個例子理解「金鑰要有足夠熵」比只背安全警語更有用。
